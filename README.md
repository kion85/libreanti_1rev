LibreAnti - Антивирусный сканер (12.08.2025)
📌 Основные функции
1. Полное сканирование системы (fullSystemScan())

Что делает: Комплексная проверка всей системы
Нельзя: Прерывать сканирование, запускать ресурсоемкие приложения
Ошибки: Может зависнуть на поврежденных файлах
Зависимости: sudo apt install clamav chkrootkit
2. Сканирование BIOS (scanBIOS())

Что делает: Проверка целостности прошивки
Нельзя: Отключать питание во время работы
Ошибки: "No SMBIOS/DMI available" на виртуальных машинах
Зависимости: sudo apt install dmidecode
3. Проверка USB (scanUSB())

Что делает: Анализ подключенных USB-устройств
Ошибки: Может не видеть некоторые скрытые устройства
Зависимости: sudo apt install usbutils
4. Диагностика железа (checkHardware())

Что делает: Показывает информацию о CPU, RAM, дисках
Зависимости: sudo apt install lshw hwinfo
5. Анализ памяти (scanMemory())

Что делает: Ищет вредоносные процессы в оперативке
Нельзя: Запускать при нехватке памяти
Ошибки: Может давать ложные срабатывания
6. Проверка прошивок (checkFirmware())

Что делает: Проверяет версии микрокода и драйверов
Зависимости: sudo apt install fwupd
7. Поиск вирусов (detectMalware())

Что делает: Сканирует систему на известные угрозы
Зависимости: sudo apt install clamav
8. Сетевой анализ (analyzeNetwork())

Что делает: Показывает открытые порты и соединения
Ошибки: Может конфликтовать с фаерволом
Зависимости: sudo apt install net-tools
⚠️ Опасные функции
10. Бэкап BIOS (backupBIOS())

Что делает: Сохраняет копию прошивки
ОЧЕНЬ ОПАСНО: Может сломать систему!
Нельзя: Прерывать процесс, использовать на ноутбуках
Зависимости: sudo apt install flashrom
🛡️ Защитные функции
14. Защита памяти (memoryProtection())

Что делает: Блокирует опасные участки памяти
Ошибки: Может конфликтовать с некоторыми приложениями
15. Анти-вымогатель (antiRansomware())

Что делает: Мониторит подозрительное шифрование файлов
Зависимости: sudo apt install inotify-tools
19. Поиск руткитов (scanRootkits())

Что делает: Ищет скрытые вредоносы
Зависимости: sudo apt install rkhunter
💡 Советы

    Всегда запускайте с sudo для полного доступа

    При ошибках смотрите логи: /var/log/libreanti.log

    Для облачного анализа (cloudSandbox) нужен интернет

    Не используйте в продакшене без тестирования!

Установка всех зависимостей:
bash

sudo apt update && sudo apt install -y \
    dmidecode usbutils lshw hwinfo \
    fwupd clamav net-tools flashrom \
    inotify-tools rkhunter chkrootkit
